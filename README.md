# Gestión de PCs Prestadas

Sistema web para registrar y administrar el préstamo de computadoras, permitiendo controlar disponibilidad, fechas y estado de los equipos.

## Funcionalidades
- Alta de PCs  
- Registro de préstamos  
- Control de fechas  
- Estado: disponible / prestada  

## Tecnologías
- HTML  
- CSS  
- JavaScript  

## Objetivo
Este proyecto corresponde a uno de mis primeros desarrollos web y fue realizado con el objetivo de aplicar conceptos básicos de frontend, adquirir experiencia práctica y organizar recursos informáticos de forma simple y funcional.
